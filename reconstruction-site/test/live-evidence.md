# Bottle reconstruction smoke test

Tested locally on 2026-09-13 through the app's actual browser upload, server API, fal queue, D1/R2 collection, Three.js preview and authenticated downloads. User supplied `references/image_object/bottle.jpeg`; the image and generated bytes are private and excluded from Git.

- Provider: original fal TRELLIS, `mesh_simplify=0.98`, `texture_size=512`.
- One real submission completed; an earlier local attempt failed synchronously before any network call because Workers does not support fetch `redirect: "error"`. Corrected to manual redirect handling, confirmed with a non-billable client request, then resolved that local job without resubmission.
- Real job submission to stored-ready: **64.966 seconds**. This is one observation, not a median, service target, or arbitrary-object quality claim. Input preparation and cold developer compilation are separate.
- Output: **1,656 vertices, 2,220 triangles**; normalized GLB **47,176 bytes**, OBJ **138,010 bytes**.
- GLB and OBJ SHA-256 values match the stored manifest. Parsing the downloaded GLB reproduces the downloaded OBJ exactly.
- The actual bottle shape rendered in Three.js; rotate and fit-to-view controls were exercised. Reload recovered the same ready job and reference image with downloads, without another generation.
- At a 390px viewport, page content width was 390px and the model panel was 358px; downloads wrapped within the viewport.
- An unauthenticated local API request returned 401; signed-in config returned configured=true. Owner isolation and adversarial cases are covered separately in synthetic tests.
- fal's read-only pricing API accepted the key and returned USD 0.02/generation. Billing totals, provider deletion/ACL guarantees, hosted identity/storage, large-device matrix, physical scale and LEGO compatibility are not established by this smoke test.

Local generation outputs are in ignored `outputs/bottle/`. No sample model is substituted by the application. Local test data is not migrated to the hosted site's separate database.
